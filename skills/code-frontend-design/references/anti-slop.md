# Anti–AI-slop patterns

Avoid interchangeable "AI product" aesthetics unless the design brief explicitly requests them.

## Red flags (replace unless brief says otherwise)

| Pattern | Prefer instead |
| ------- | -------------- |
| Purple/violet gradient hero on white | Brand accent from brief; neutral surfaces |
| Identical rounded cards in a 3-column grid | Content-driven layout; asymmetry where it helps scan |
| Generic hero + three feature cards | Lead with user job; show real UI preview |
| Inter/Roboto only with no scale | Distinct pairing from brief or context-appropriate fonts |
| Decorative blobs / glassmorphism everywhere | Restraint; one focal treatment |
| Lorem ipsum placeholders in shipped UI | Realistic labels from domain |

## Positive signals

- Clear typographic scale (display → body → caption)
- Consistent spacing rhythm (4/8px or project token)
- Meaningful empty and loading states
- Focus styles visible without garish outlines
- Dark mode considered when app supports it

## Before shipping UI

Ask: *Would ten SaaS landing pages look the same?* If yes, differentiate one element (type, layout, accent, motion).
