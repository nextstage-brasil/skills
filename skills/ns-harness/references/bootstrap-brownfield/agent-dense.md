# Agent-dense writing (brownfield map)

`brownfield-map.md` = cold agent context, not essay.

Before Write: `../agent-artifact-compress.md`.

## Rules

1. **Tables + one-liners only** — no overview paragraphs, no narrative recommendations.
2. **No stack duplication** — `architecture-rules.md` exists → link; stack row only for deltas or missing/stub constitution.
3. **Counts over prose** — module rows = numbers (or `—`); caveats in one `Notes` cell.
4. **Gaps = priority table** — P1/P2/P3; Next planning ≤3 bullets (no recommendation essays).
5. **Size** — prefer ≤120 lines; hard soft-cap ~180.
